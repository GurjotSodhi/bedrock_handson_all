::::alert{header="AWS Builder center or AWS-run events only" type="error"}
The AgentCore labs are designed to run only from AWS Builder Center or an AWS-operated workshop event.
::::

:::alert{header="Workspace setup" type="info"}
These labs use the `/environment` folder as the working directory. If your IDE has a different folder open, switch back using **☰ → File → Open Folder**

Alternatively, you can run :code[code /environment --reuse-window]{showCopyAction=true} from the web IDE's terminal.
:::




If you are running from your own account, you can follow the [series published here](https://builder.aws.com/content/38ooxopwKSyth7Wa9dVTdrmnGL7/series-overview-agentic-applications-with-amazon-bedrock).
